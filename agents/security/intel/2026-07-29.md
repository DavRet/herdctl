## What Changed Since Last Audit (2026-03-06)

### Security Fixes (Critical → Fixed)

#### 1. **Tool Permission Bypass** (Commit 38a408d) - CRITICAL FIX
- **Issue:** SDK runtime was ignoring `denied_tools` configuration
- **Root cause:** Used `deniedTools` instead of correct `disallowedTools` SDK field
- **Impact:** Tools listed in `denied_tools` remained available to agents using SDK runtime
- **Severity:** **CRITICAL** - complete permission bypass vulnerability
- **Fix:** Corrected field name mapping
- **Status:** ✅ FIXED with regression test coverage

#### 2. **Windows Path Traversal Protection** (Commit 31c675c) - HIGH FIX
- **Issue:** Hardcoded `/` separator broke protection on Windows
- **Root cause:** Used `includes('/')` instead of `path.sep`
- **Impact:** Path traversal attacks could succeed on Windows systems
- **Fix:** Now uses `path.sep` and handles root paths correctly
- **Status:** ✅ FIXED with Windows-specific test coverage

#### 3. **Session Path Encoding Collisions** (Commit 9e0b6fc) - MEDIUM FIX
- **Issue:** Different working directories could map to same session directory
- **Examples:** `/a/b-c`, `/a-b/c`, `/a/b/c` → all became `a-b-c`
- **Impact:** Session data incorrectly shared between distinct agents
- **Fix:** Disambiguate using authoritative cwd from transcript JSONL
- **Status:** ✅ FIXED

#### 4. **OAuth Token Refresh for Persistent Containers** (Commit 18834f8) - MEDIUM FIX
- **Issue:** Refreshed credentials never reached reused containers
- **Root cause:** Environment variables fixed at container creation time
- **Impact:** Persistent containers looped on expired credentials
- **Fix:** Re-inject credential env on every exec (SDK via `Env`, CLI via `docker exec -e`)
- **Security:** Credential values never logged
- **Status:** ✅ FIXED with regression test

#### 5. **Web Session Expiry Configuration** (Commit 03c6a31) - LOW FIX
- **Issue:** `web.session_expiry_hours` config value ignored
- **Impact:** Session expiry policy hardcoded to 24 hours
- **Fix:** Config value now properly honored
- **Status:** ✅ FIXED

### New Attack Surface

#### File Serving Endpoint (Commit 28d4d74) - Well-Secured

**Feature:** GET `/files/:agentName/*` serves agent working directory files (for inline images)

**Attack Vectors Addressed:**
1. **Path traversal** (`../../../etc/passwd`)
   - ✅ Realpath-based containment check
   - ✅ Structural safety pre-check before filesystem operations
   - ✅ Test coverage: path escape, symlink escape

2. **MIME sniffing attacks**
   - ✅ `X-Content-Type-Options: nosniff` header

3. **Script execution via SVG/HTML**
   - ✅ Content-Security-Policy: `default-src 'none'; sandbox`
   - ✅ Prevents inline scripts, eval, external loads

4. **Directory enumeration**
   - ✅ Directories return 404 (only regular files served)

5. **TOCTOU race conditions**
   - ✅ Single file handle for stat + read

**Assessment:** ✅ **Secure** - comprehensive defense-in-depth implementation
