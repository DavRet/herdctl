## What Changed Since Last Audit

### Security Fixes

1. **Tool Permission Bypass (CRITICAL FIX)** - Commit 38a408d
   - SDK runtime was ignoring `denied_tools` configuration
   - Used wrong field name (`deniedTools` vs `disallowedTools`)
   - **Impact:** Complete permission bypass for SDK runtime agents
   - **Status:** ✅ FIXED with regression test

2. **Windows Path Traversal** - Commit 31c675c
   - Hardcoded `/` separator broke protection on Windows
   - **Impact:** Path traversal attacks could succeed on Windows
   - **Status:** ✅ FIXED with cross-platform tests

3. **Session Path Collisions** - Commit 9e0b6fc
   - Different working directories could share session data
   - **Status:** ✅ FIXED with authoritative cwd disambiguation

4. **OAuth Token Refresh** - Commit 18834f8
   - Persistent containers couldn't receive refreshed credentials
   - **Status:** ✅ FIXED with env re-injection on exec

5. **Web Session Expiry** - Commit 03c6a31
   - Configuration value was ignored (hardcoded 24h)
   - **Status:** ✅ FIXED

### New Attack Surface

**File Serving Endpoint** (Commit 28d4d74) - GET `/files/:agentName/*`
- **Purpose:** Serve agent-produced files for inline images
- **Security:**
  - ✅ Realpath-based path traversal protection
  - ✅ CSP: `default-src 'none'; sandbox` (prevents script execution)
  - ✅ X-Content-Type-Options: nosniff (prevents MIME attacks)
  - ✅ TOCTOU protection (single file handle)
  - ✅ Directory rejection (only regular files)
  - ✅ Comprehensive test coverage
- **Assessment:** ✅ Well-secured with defense-in-depth
